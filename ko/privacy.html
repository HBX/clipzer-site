Clipzer 개인정보 처리방침

시행일: 2026년 7월 23일

본 개인정보 처리방침은 Changsha Imaginary Technology Co., Ltd가 Clipzer에서 정보를 처리하는 방식을 설명합니다. Clipzer는 클립보드 기록, 빠른 메모, 이미지 압축 및 유틸리티 도구를 제공하는 로컬 우선 macOS 메뉴 막대 앱입니다.

1. 로컬 처리

Clipzer는 클립보드 기록, 빠른 메모, 설정, 단축키 설정, 제외 앱 목록 및 도구 임시 데이터를 사용자의 Mac에 저장합니다. 이미지 압축과 기타 도구 처리도 기기에서 로컬로 완료됩니다.

2. 수집하지 않는 데이터

  • 클립보드 내용을 수집, 업로드 또는 원격 저장하지 않습니다.
  • 빠른 메모 내용을 수집, 업로드 또는 원격 저장하지 않습니다.
  • 이미지, 도구 입력 내용 또는 도구 출력 결과를 업로드하지 않습니다.
  • 계정을 만들지 않으며 클라우드 동기화를 제공하지 않습니다.
  • 광고, 분석, 충돌 보고 또는 타사 추적을 포함하지 않습니다.

3. 클립보드, 메모, 이미지 및 도구 데이터

사용자가 복사한 내용, 저장한 빠른 메모, 처리하도록 선택한 이미지, 도구에 입력하거나 도구에서 생성한 내용은 사용자가 기기에서 직접 시작한 작업을 완료하는 데에만 사용됩니다. Clipzer는 이러한 데이터를 당사나 타사 서버로 전송하지 않습니다.

4. 시스템 권한

Clipzer는 사용자가 실행하는 단축키, 선택한 텍스트 읽기 또는 바꾸기, 대상 앱으로 다시 붙여넣기를 위해 macOS 손쉬운 사용 권한을 요청할 수 있습니다. 이 권한은 로컬 기능에만 사용되며 데이터 수집이나 업로드에는 사용되지 않습니다.

5. Mac App Store

Clipzer는 Mac App Store를 통해 배포되고 구매됩니다. 구매, 환불, 청구 및 스토어 관련 데이터는 Apple의 정책에 따라 Apple이 처리합니다. 당사는 Clipzer에서 이러한 데이터를 수집하지 않습니다.

6. 데이터 삭제

Clipzer 안에서 개별 클립보드 기록을 삭제하거나 기록을 비우거나 빠른 메모를 삭제할 수 있습니다. 또한 macOS에서 앱과 관련 로컬 앱 데이터를 삭제할 수 있습니다. 로컬 데이터를 삭제한 후에는 당사가 복구할 수 없습니다.

7. 본 방침의 업데이트

Clipzer의 데이터 처리 방식이 변경되면 본 개인정보 처리방침을 업데이트하고 이 페이지에 새로운 시행일을 게시합니다.
